CO227 TEAM PROJECT · ENGEX 2025

PERAVERSE - Smart Info Kiosk

An interactive kiosk system for EngEx 2025 that brings real-time notifications, event and exhibit information, venue navigation, digital maps, chatbot assistance, and visitor feedback into one user-friendly experience.

ReactViteExpress.js Node.jsPostgreSQLFull-stack JavaScriptCSSTypeScript Batchfile

Project overview

PERAVERSE was developed by a team of nine for CO227 at the Department of Computer Engineering, University of Peradeniya. The interactive kiosk was designed for EngEx 2025 to help visitors access exhibition information, discover exhibits, navigate the venue, and engage with events through a seamless, approachable interface.

My contribution

My contribution focused on developing the AI chatbot, helping visitors ask questions about the exhibition and find relevant information through a conversational interface.

Solution & impact

PeraVerse consolidates campus and exhibition services into a single kiosk interface for visitors and staff. Centralized schedules, notifications, exhibit information, maps, and feedback make event information easier to find and encourage engagement. Heatmap data can also support crowd monitoring and event planning.

Features

  • Event schedules, categories, event creation, and notifications.
  • Exhibit information, categories, descriptions, and location details.
  • Digital maps, building search, and route finding for venue navigation.
  • Heatmap generation and visualization for crowd monitoring.
  • Chatbot and knowledge-base assistance for visitor questions.
  • Visitor feedback collection and exhibit information pages.

Architecture

The frontend is built with React and Vite, with UI components and feature modules in the frontend application. It communicates with Node.js and Express REST services for events, maps, heatmaps, notifications, and other content. The services use PostgreSQL for data storage. Backend services are configured with environment settings, while the frontend uses a Vite API URL setting to connect to the appropriate backend.
