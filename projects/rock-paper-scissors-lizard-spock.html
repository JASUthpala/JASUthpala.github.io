GP 106 · FIRST-YEAR TEAM PROJECT

Rock Paper Scissors Lizard Spock

A five-choice game combining an Arduino circuit and a Kivy interface, developed as a GP 106 Computing group project.

ArduinoPythonPyFirmata KivyEmbedded Systems

Project overview

This first-year, second-semester group project extends the classic game with Lizard and Spock choices. Five choice buttons and an on/off control are connected to an Arduino; ten LEDs display moves and scores in binary, while a buzzer provides sound feedback. The Arduino is programmed in Python with PyFirmata, and a Kivy graphical interface provides another way to interact with the game. The project provided practical experience with microcontrollers, circuitry, Python, and hardware-software integration.
